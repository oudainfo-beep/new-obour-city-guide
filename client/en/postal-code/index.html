Obour City Postal Code: The Practical Guide

The postal code for Obour City, Qalyubia is 11828. Learn how Egyptian postal codes work, how to write a full Obour address, and how to verify your street's code officially with Egypt Post.

If you are filling in a bank form, ordering an international shipment, or registering an address in Egypt, you will eventually hit the same question: what is the postal code of Obour City? This short guide gives you the answer, explains how Egyptian postal codes work, and shows you how to verify your exact street's code officially.

The quick answer

Obour City — administratively part of Qalyubia Governorate — is commonly served by the postal code 11828. Because Obour contains numbered districts and borders the newer New Obour development, treat this as the city's general code and verify your specific street with Egypt Post before using it on binding documents.

How Egyptian postal codes work

Egypt uses a five-digit postal code system managed by Egypt Post. The digits route mail from regional sorting down to the local post office level, which is why two neighboring areas can share or split codes depending on which office serves them. Greater Cairo's eastern cities — including Obour — fall within the 11xxx range, which covers much of Cairo and the surrounding Qalyubia urban belt.

For everyday life inside Egypt, you will notice that private couriers rarely ask for the code at all; they run on phone numbers, landmarks, and live map pins. The postal code becomes genuinely important in three situations: official and banking paperwork, government services, and international mail and online orders that validate the field automatically.

Writing an Obour address correctly

A complete address for mail or forms typically looks like this:

  • Building number, street name, and district (e.g. 1st District / الحي الأول)
  • Obour City (مدينة العبور)
  • Qalyubia Governorate (محافظة القليوبية)
  • Postal code: 11828 — Egypt

Include both the district name and a landmark when dealing with couriers; include the postal code when dealing with institutions. If you are still learning the city's layout, the districts guide and the city map will help you pin your exact location.

How to verify your exact code

  1. Check Egypt Post's official postal-code lookup service online with your full address.
  2. Or ask at the nearest post office branch — staff can confirm the code for your street in a minute.
  3. If a form rejects the code, do not guess a neighbor's code; verify first, because a wrong code can delay official mail.

Bottom line

For most purposes, Obour City's postal code is 11828, under Qalyubia Governorate. Verify your street's code with Egypt Post for official paperwork, and use landmarks plus a phone number for couriers. Settling in? Continue with the Obour living guide for utilities, transport, and daily services.

Frequently asked questions

What is the postal code of Obour City, Egypt?

Obour City in Qalyubia Governorate is commonly served by the postal code 11828. Postal boundaries occasionally differ between adjacent districts, so confirm the exact code for your street with Egypt Post before official paperwork.

Is Obour City in Cairo or Qalyubia?

Administratively, Obour City belongs to Qalyubia Governorate, not Cairo, even though it sits directly on the Cairo-Ismailia Desert Road and functions as part of Greater Cairo's eastern urban area. This matters for paperwork and addresses.

Do couriers in Egypt actually use postal codes?

Most private couriers rely on phone numbers and landmark-based addresses rather than postal codes. The postal code matters mainly for official documents, bank forms, government services, and international shipments.

How do I verify an Egyptian postal code officially?

Use Egypt Post's official code lookup or ask at your local post office with your full street address. Codes can change or split as districts grow, so a two-minute check prevents rejected forms later.
